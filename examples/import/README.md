# Beispieldateien für den Import

Zum Ausprobieren unter *Musikbibliothek → Import und Export* hochladen. Was jede Datei zeigt
und welche Spalten unterstützt werden, steht in [docs/IMPORT_EXPORT.md](../../docs/IMPORT_EXPORT.md).

IDs, ISRCs und Links sind zur Veranschaulichung gewählt und zeigen nicht zwingend auf die
genannten Titel. Die Dateien dienen zugleich als Testdaten (`backend/tests/test_import_*.py`).
